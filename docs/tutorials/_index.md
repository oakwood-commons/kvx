# Tutorials

Follow these six progressive tutorials to master `kvx` from first install through schema-driven terminal views and custom themes:

1. [Getting Started](getting-started/): Install `kvx`, inspect your first file, filter with `--where`, and switch output modes
2. [Interactive Mode](interactive-mode/): Navigate trees, search keys and values, copy paths or values, and script `--snapshot` runs
3. [CEL Expressions](expressions/): Query and transform data with CEL, ghost completion, and the `Ctrl+Space` Function Palette
4. [Formats, JWTs & Decoding](formats-and-decoding/): Work with JSON, YAML, TOML, NDJSON, CSV, `Bearer` JWTs, and serialized string leaves
5. [Schema-Driven Views](schema-views/): Turn JSON Schemas into Card-List (`x-kvx-list`), Detail (`x-kvx-detail`), and Status (`x-kvx-status`) screens
6. [Configuration & Themes](configuration/): Browse the visual theme gallery, customize keybindings, and set up shell completion
